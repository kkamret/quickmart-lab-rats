# 사례 ④ Netflix: 추천 랭킹 인터리빙과 결선 A/B

## 0. 메타
- 원문: Netflix Technology Blog 「Innovating Faster on Personalization Algorithms at Netflix Using Interleaving」(Aurisset, Ramm, Parks, 2017)
  - 구현 전 반드시 원문을 다시 읽고 아래 "확인된 사실" 표를 검증할 것. 확인되지 않은 수치는 화면에 쓰지 않는다.
- 화면 속 서비스명: 가상 OTT ‘플릭스’ (원문 기법을 각색한 시나리오임을 명시)
- 난이도 ★★★★ / 권장: 통계와 ML 배경이 있는 조
- 커버 개념: 오프라인 지표와 온라인 성과의 간극, 실험 감도(sensitivity)와 검정력, 인터리빙(Team Draft vs Balanced), 위치 편향, 성과 귀속 정의(클릭 vs 충분한 시청 → Goodhart), 다수 후보 스크리닝과 다중검정, 2단계 실험 퍼널, 꼬리가 긴 평균 지표(시청 시간)와 윈저라이징·로그 변환, CUPED, 신규성 효과, 대리 지표(surrogate), 장기 홀드아웃, Multi-armed Bandit의 탐색·활용 트레이드오프

### 원문에서 확인된 사실 (구현 시 재검증)
- Netflix는 개인화 랭킹 알고리즘의 실험 속도를 높이기 위해 인터리빙을 쓴다
- 1단계: 인터리빙으로 많은 후보 중 유망한 랭커를 적은 표본으로 빠르게 골라낸다
- 2단계: 걸러진 소수 후보만 전통적 A/B 테스트로 핵심 지표를 검증한다
- 인터리빙은 두 랭커의 결과를 한 사용자의 목록에 섞어 선호를 직접 비교하므로, 그룹 간 비교인 A/B보다 감도가 높다
- 위 외의 모든 수치(후보 수, 효과 크기, 표본)는 교육용 가상값

## 2. 후보 랭커와 진짜 효과 (숨김)
| 랭커 | 오프라인 NDCG 순위 | 인터리빙 선호(충분 시청 귀속) | 인터리빙 선호(재생 시작 귀속) | 주간 시청 시간 | 28일 리텐션 | 비고 |
|---|---|---|---|---|---|---|
| R0 | (현행) | 0.500 | 0.500 | 0 | 0 | 기준 |
| R1 | 1위 | 0.505 | 0.508 | +0.2% | 0 | 오프라인 최고, 온라인 미미 |
| R2 | 4위 | 0.512 | **0.560** | +0.4% | 0 | 썸네일 클릭 유도형: 재생 시작↑, 2분 내 이탈↑ |
| R3 | 3위 | **0.524** | 0.515 | **+1.1%** | **+0.15%p** | 진짜 최선 |
| R4 | 2위 | 0.518 | 0.520 | +0.8% | +0.08%p | 차선 |
| R5 | 5위 | 0.500 | 0.503 | 0 | 0 | |
| R6 | 6위 | 0.490 | 0.492 | −0.6% | −0.05%p | 열등 |
| R7 | 7위 | 0.512 | 0.506 | +0.5% | +0.03%p | |
| R8 | 8위 | 0.497 | 0.501 | 0 | 0 | |
- "인터리빙 선호" = 한 멤버의 섞인 목록에서 해당 랭커 몫 타이틀이 R0 몫보다 더 많이 선택될 확률(무승부 제외)
- 신규성 효과: 새 랭커는 처음 며칠 탐색이 늘어 시청 시간이 추가로 오르고, 지수 감쇠라 대부분 첫 주 안에 사그라든다(8일째 첫날의 약 17%가 남고 2주차 이후는 미미). `+1.5% × exp(−(d−1)/4)`, R2는 `+3.0%`
- 리텐션 효과는 습관 형성을 거쳐 서서히 나타남: 관측되는 효과 = 정상 상태 효과 × min(1, 경과 주 / 10). 4주 결선이면 R3 리텐션 효과의 40%(+0.06%p)만 보임
- 위치 편향: Balanced 인터리빙에서 첫 슬롯을 항상 같은 랭커가 가져가면 그 랭커 선호에 **+0.015** 편향. Team Draft(매 라운드 무작위 선픽)는 편향 없음

### 2-1. 감도 차이 (엔진이 재현해야 할 구조)
- 인터리빙: 멤버 단위 이항 비교(선호 vs 0.5 의 한 표본 z 검정). 선호 0.52를 80% 검정력으로 잡는 데 쌍당 약 5천 명(약 4,900명, Bonferroni 8개 보정 시 약 8,000명). 쌍당 1만 명이면 검정력 약 0.98
- A/B 시청 시간 +1%(유의수준 5%, 검정력 80%): 1주 창 기준 그룹당 원시 평균 약 30만 명, 윈저라이징(p99) 약 25만 명, CUPED까지 약 14만 명. 4주 창 기준 약 26만 / 22만 / 12만 명(같은 멤버의 주별 시청이 상관되어 있어 기간이 길어져도 크게 줄지 않음)
- A/B 리텐션 +0.15%p: 그룹당 약 45만 명, 그리고 지표 특성상 최소 4주 이상 관찰 필요

## 3. 설계 입력 (zod) → 결과 반영

### 3-1. s1_diagnose
```ts
{ ship_offline_best: 'yes'|'no', reason: string, offline_online_risks: string[] }
```
- 채점: 'no' + 오프라인-온라인 간극(학습 데이터 편향, 피드백 루프, 목표 지표 불일치) 언급 시 만점. 'yes'면 `OFFLINE_ONLINE_GAP`

### 3-2. s2_design (스크리닝)
```ts
{
  method: 'abn_all'|'interleaving',
  // abn_all
  abn_primary?: 'hours'|'retention', abn_fraction?: number, abn_weeks?: number,
  // interleaving
  il_scheme?: 'team_draft'|'balanced_fixed_first',
  il_credit?: 'play_start'|'qualified_play_10min',
  il_members_per_pair?: number, il_days?: number,
  candidates: ('R1'|'R2'|'R3'|'R4'|'R5'|'R6'|'R7'|'R8')[],
  correction: 'none'|'bonferroni'|'bh',
  advance_rule: string    // 결선 진출 기준(예: 보정 후 유의 + 선호 0.51 이상)
}
```
| 설계 | 결과 |
|---|---|
| abn_all + hours, 9군, 2주 | 그룹당 표본이 부족해 대부분 "차이 없음", 소요 멤버 수와 기간 경고 → `UNDERPOWERED`(Bonferroni 보정 기준 검정력 약 0.22. BH·보정 없음은 계획 유의수준이 0.05 라 검정력 약 0.50 으로 기준선에 걸려 플래그가 뜨지 않을 수 있음) |
| abn_all + retention | 기간 내 판단 불가 수준(검정력 < 0.2) |
| interleaving + team_draft + qualified_play | 선호 순위가 진짜 효과 순서와 거의 일치(R3 > R4 > R2·R7 > R1) |
| interleaving + play_start | R2가 압도적 1위(0.56) → 결선에 R2가 올라감 → `GOODHART` |
| balanced_fixed_first | 모든 후보에 +0.015 편향, R5·R8 같은 무효 후보도 유의해짐 → `POSITION_BIAS` |
| correction = none, 8개 후보 | 무효에 가까운 후보가 우연히 유의할 수 있음. CRN 고정에서는 R1(진짜 선호 0.505, 쌍당 1만 명에서 기대 z 약 1)이 p < 0.05 로 나오고, BH 로 보정하면 사라짐 → `MULTIPLE_TESTING` |

### 3-3. s4 Readout (스크리닝)
- 후보별 선호 추정치·CI·p, 일별 선호 추이, 귀속 방식별 비교(설계에서 고른 것만 기본 표시, 다른 귀속은 "다른 기준으로 보기" 토글로만 열림 → 조가 직접 의심해야 발견)
- 결정: 결선 후보 2~3개 선택(+ 사유)

### 3-4. s5_deep (결선 A/B)
```ts
{
  finalists: string[],          // 2~3개 + R0 자동 포함
  fraction: number,             // 멤버 중 실험 비율 (≤ 0.20)
  weeks: number,                // 1~8
  primary: 'hours'|'retention'|'surrogate_2ep',
  hours_treatment: 'raw'|'winsorize_p99'|'log',
  cuped: boolean,
  correction, stopping: 'fixed'|'peek_stop'|'sequential',
  exclude_first_week: boolean   // 신규성 구간 제외 분석
}
```
| 설계 | 결과 |
|---|---|
| R2 포함, weeks ≤ 2 | 신규성으로 R2 시청 시간 유의 상승처럼 보임 → `NOVELTY` |
| R2 포함, exclude_first_week | R2 효과가 정상 상태 약 +0.4% 로 줄어 R3(+1.1%)보다 확연히 작음. 표본이 크면 작지만 유의할 수도 있음(노이즈 draw 에 따라 갈림). 2분 내 이탈 증가 |
| R2 포함, weeks ≥ 4 이지만 첫 주 포함 | 신규성이 평균에 남아 R2 가 기대값 약 +0.7~0.9% 로 부풀려 보임(`NOVELTY` 는 4주 미만에서만 뜸) → 주별 시계열의 1주차 급등을 확인 |
| R3, hours raw(첫 주 제외), 그룹당 약 15만 명 미만 | 검정력 0.7 미만으로 경계(기대 p: 그룹당 10만 명 약 0.045, 5만 명 약 0.16). 윈저라이징하면 추정치가 상대적으로 약 5~10% 줄고 CI 가 좁아짐(고래 몇 명이 추정을 뒤집는 수준은 아님) |
| R3, winsorize_p99 + cuped | +1.1% 명확히 유의 |
| log 변환 | 유의는 잘 나오지만 해석이 "기하평균 변화"임을 해설(평균 시청 시간과 다름) |
| primary = retention, 4주 | 관측 효과 +0.06%p(정상 상태의 40%), 검정력 약 0.2 → 대개 유의 아님 → `UNDERPOWERED` |
| primary = surrogate_2ep | R3에서 유의. 대리 지표의 타당성(리텐션과의 상관 0.45, 인과 연결 가정)을 해설. 대리 지표에는 신규성을 얹지 않으므로 짧게 봐도 `NOVELTY` 없음(`NOVELTY` 는 메인이 시청 시간이고 첫 주를 포함해 4주 미만에 끝났을 때만) |
| peek_stop | 첫 주를 빼지 않으면 신규성 구간인 1주차에 종료 → `PEEKED` + `NOVELTY`. exclude_first_week 면 분석 첫 주인 2주차에 종료 → `PEEKED` |
| sequential | 표본이 크면(10% 등) 효과가 커서 O'Brien-Fleming 경계도 넘으므로, 첫 주를 빼지 않으면 신규성 구간인 1주차에 종료되고 `NOVELTY` 가 뜬다(`PEEKED` 는 아님). 중간 확인 규칙이 무엇이든 결과의 종료 주차를 확인해야 함 |

### 3-5. s6_final
```ts
{ ship: 'R3'|'R4'|'R2'|'none', long_term: 'holdout'|'extend'|'bandit'|'none',
  holdout_pct?: number, holdout_months?: number, rationale: string }
```
- `bandit` 선택 시 시뮬레이션 패널: Thompson Sampling으로 결선 후보에 트래픽을 몰아주면 누적 시청 손실(regret)은 줄지만, 리텐션처럼 피드백이 4주 걸리는 지표에는 부적합하고 효과 추정이 편향됨을 그래프로 보여줌

## 4. 함정과 발견 경로
| 함정 | 발견 경로 |
|---|---|
| 오프라인-온라인 간극 | 오프라인 1위 R1이 인터리빙·A/B 모두 미미 |
| 귀속 정의(Goodhart) | "다른 기준으로 보기"에서 R2 선호가 귀속에 따라 0.56 ↔ 0.51로 급변 |
| 위치 편향 | 무효 후보까지 일제히 0.515 근처로 상승 |
| 다중검정 | 보정 전후 결선 진출 후보 변화 |
| 신규성 | 결선 주별 시계열에서 1주차 급등 후 하락 |
| 꼬리 지표 | 원시 평균 CI가 넓고, 윈저라이징(p99)하면 추정치가 상대적으로 약 5~10% 이동하고 CI 가 좁아짐 |
| 리텐션 검정력 | 4주 리텐션이 유의하지 않은 이유 계산 |

## 5. 루브릭
| 스텝 | 모범 답 |
|---|---|
| s1 | 오프라인 1위를 바로 출시하지 않음, 온라인 검증 필요 근거 |
| s2 | 인터리빙 + Team Draft + 충분 시청 귀속 + 보정(BH 등) + 사전 진출 기준 |
| s4 | R3, R4(+ 필요 시 R7) 진출. R2를 올렸다면 귀속 기준을 점검했는지 |
| s5 | 4주 이상, 신규성 구간 처리, 윈저라이징 + CUPED, 메인은 시청 시간(리텐션은 장기 검증 대상) |
| s6 | R3 출시 + 장기 홀드아웃(예: 5%, 3개월)으로 리텐션 확인. 밴딧은 피드백 지연 때문에 부적합하다고 설명하면 가산 |

### reveal 해설 요지
원문의 핵심은 2단계 구조다. 감도가 높은 인터리빙으로 많은 후보를 빠르게 걸러내고, 살아남은 후보만 A/B로 핵심 지표를 검증한다. 인터리빙이 보는 것은 "사용자가 어느 랭커의 결과를 더 선호하는가"이고, 그것이 곧 사업 지표 개선을 보장하지는 않기 때문에 2단계가 필요하다. (원문 수치는 구현 시 재확인 후 해설에 추가)

## 6. 검증 시나리오 (Vitest)
| # | 설계 | 기대 |
|---|---|---|
| 1 | interleaving, team_draft, qualified_play, 쌍당 1만 명, 7일, bh | R3·R4 유의, R2·R7 경계 또는 유의, R5·R8 유의 아님 |
| 2 | 1과 같되 play_start | R2 1위(0.55 이상), `GOODHART` |
