# A/B 테스트 기초용어

수업을 이해하기 위해 먼저 알아두면 좋은 용어를 짧게 정리했습니다. 정확한 계산 방법과 활용 기준은 각 본문에서 자세히 다룹니다.

## 실험의 기본 구조

**A/B 테스트(A/B Test)**: 사용자를 둘 이상의 집단으로 나누어 서로 다른 버전을 보여주고, 결과 차이를 비교하는 실험입니다.

**대조군(Control)**: 현재 사용 중인 기존 버전을 경험하는 비교 기준 집단입니다.

**실험군(Treatment Group)**: 검증하려는 새로운 변화가 적용된 집단입니다.

**변형군(Variant)**: 실험에서 비교하는 각 버전입니다. 대조군과 하나 이상의 실험군을 모두 가리킬 수 있습니다.

**처치(Treatment)**: 실험군에만 적용하는 기능, 정책, 화면 등의 변화입니다.

**결과(Outcome)**: 처치 이후 사용자에게 나타난 행동이나 성과입니다.

**무작위 배정(Randomization)**: 사용자를 임의로 집단에 배정해 두 집단의 조건을 최대한 비슷하게 만드는 과정입니다.

**실험 단위(Experimental Unit)**: 실험군과 대조군 중 하나에 배정되는 대상입니다. 사용자, 세션, 지역 등이 될 수 있습니다.

**분석 단위(Analysis Unit)**: 결과를 계산하고 비교하는 단위입니다. 실험 단위와 다르면 분석 방법에 주의해야 합니다.

**모집단(Population)**: 실험 결과를 적용하고 싶은 전체 대상입니다.

**표본(Sample)**: 실제 실험에 참여해 관측된 대상입니다.

## 가설과 지표

**가설(Hypothesis)**: 어떤 변화를 적용했을 때 특정 지표가 어떻게 달라질지 미리 세운 주장입니다.

**귀무가설(Null Hypothesis, H0)**: 실험군과 대조군 사이에 효과나 차이가 없다고 보는 가설입니다.

**대립가설(Alternative Hypothesis, H1)**: 실험군과 대조군 사이에 효과나 차이가 있다고 보는 가설입니다.

**지표(Metric)**: 실험 결과를 판단하기 위해 측정하는 수치입니다.

**전환(Conversion)**: 구매, 예약, 가입처럼 실험에서 목표로 정한 행동입니다.

**전환율(Conversion Rate, CVR)**: 전체 대상 중 목표 행동을 완료한 대상의 비율입니다.

**Primary Metric**: 실험의 핵심 가설을 판단하는 가장 중요한 지표입니다.

**Secondary Metric**: 실험의 영향을 추가로 이해하기 위해 함께 살펴보는 보조 지표입니다.

**Driver Metric**: Primary Metric이 어떤 경로로 변했는지 설명하는 과정 지표입니다.

**Guardrail Metric**: 핵심 지표를 개선하는 동안 사용자 경험이나 서비스 안정성이 나빠지지 않았는지 확인하는 안전 지표입니다.

**OEC(Overall Evaluation Criterion)**: 실험 결과를 종합해 전체적으로 좋은 변화였는지 판단하는 기준입니다.

## 통계적 판단

**기준값(Baseline)**: 실험 전이나 대조군에서 관측된 비교 기준 수치입니다.

**효과 크기(Effect Size)**: 실험군과 대조군 사이에 나타난 차이의 크기입니다.

**상대적 변화율(Relative Lift)**: 기준값과 비교해 지표가 몇 퍼센트 변했는지를 나타낸 값입니다.

**최소 검출 효과(Minimum Detectable Effect, MDE)**: 실험에서 찾아내고자 미리 정한 최소한의 의미 있는 차이입니다.

**유의수준(Significance Level, α)**: 실제 효과가 없는데 효과가 있다고 잘못 판단할 위험을 허용하는 기준입니다. 흔히 0.05를 사용합니다.

**p-value**: 귀무가설이 참이라고 가정했을 때, 현재 결과와 같거나 더 극단적인 결과가 나올 가능성을 나타내는 값입니다.

**통계적 유의성(Statistical Significance)**: 관측된 차이를 우연만으로 설명하기 어렵다고 판단한 상태입니다. 실무적으로 중요한 차이라는 뜻과는 다릅니다.

**신뢰구간(Confidence Interval, CI)**: 실제 효과가 있을 것으로 추정되는 범위를 보여줍니다. 추정값의 불확실성을 함께 확인할 수 있습니다.

**검정력(Power)**: 실제 효과가 있을 때 실험이 그 효과를 발견할 확률입니다.

**1종 오류(Type I Error)**: 실제 효과가 없는데 있다고 판단하는 오류입니다.

**2종 오류(Type II Error)**: 실제 효과가 있는데 없다고 판단하는 오류입니다.

**단측검정(One-sided Test)**: 미리 정한 한 방향의 변화만 검정하는 방법입니다.

**양측검정(Two-sided Test)**: 증가와 감소를 모두 포함해 두 집단의 차이를 검정하는 방법입니다.

## 실험 운영과 점검

**A/A 테스트**: 두 집단에 같은 버전을 보여주어 배정과 데이터 수집 시스템이 정상인지 확인하는 실험입니다.

**Ramp-up**: 실험 노출 비율을 조금씩 늘리며 오류와 위험을 점검하는 운영 방식입니다.

**SRM(Sample Ratio Mismatch)**: 실제 집단별 표본 비율이 계획한 배정 비율과 비정상적으로 달라진 상태입니다.

**Peeking**: 실험이 끝나기 전에 결과를 반복해서 확인하고, 유리한 시점에 실험을 중단하는 행동입니다.

**다중검정(Multiple Testing)**: 여러 지표나 가설을 동시에 검정해 우연한 유의 결과가 나올 가능성이 커지는 문제입니다.

**SUTVA**: 한 사용자의 결과가 다른 사용자의 배정이나 처치에 영향을 받지 않는다는 실험의 기본 가정입니다.

**간섭(Interference)**: 한 사용자가 받은 처치가 다른 사용자의 결과에도 영향을 미치는 현상입니다.

**CUPED**: 실험 전 데이터를 활용해 결과의 분산을 줄이고 실험의 민감도를 높이는 방법입니다.
