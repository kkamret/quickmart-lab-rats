# 넷플릭스(가상 OTT '플릭스') 보정 기록

docs/cases/netflix.md §6 검증 시나리오 12개를 기준으로 조정한 값과, 스펙 밖으로 나간 결정을 기록한다. 수치는 모두 교육용 가상 데이터다.
원문(Netflix Technology Blog, 2017)에서 확인한 것은 "2단계 구조(인터리빙으로 빠르게 거르고, 남은 후보만 A/B)"와 "인터리빙은 A/B 보다 감도가 높다"뿐이다.

## 조정한 노브 (스펙 ±50% 이내)
| 항목 | 스펙 | 값 | 비고 |
|---|---|---|---|
| CUPED 상관 `RHO_CUPED` | 0.65 | 0.68 (+5%) | 결선은 여러 주 평균이라 상관이 더 높다고 보고 올림. 시나리오 8(원시 대비 CI 폭 1.6배)을 맞추기 위한 값 |
| 인터리빙 노이즈 salt `SALT.il` | – | 136 | 시나리오 1~4 가 한꺼번에 성립하는 값을 0~199 에서 탐색(통과 3개 중 선택) |
| A/B 노이즈 salt `SALT.ab` | – | 4 | 시나리오 5·6·7·9 가 한꺼번에 성립하는 값을 0~199 에서 탐색(통과 16개 중 선택). 밴딧 난수에도 같은 salt 를 쓴다 |

## 스펙에 값이 없어 가상으로 둔 것
- 시청 시간 로그정규의 (mu, sigma) = (1.5285, 0.971): 평균 6.5, SD 9.0, 0 질량 0.12 를 만족하도록 풀었다. 로그정규 성분 중앙값 약 4.6시간(스펙 4.5), 0 질량을 포함한 전체 중앙값 약 3.9시간, 고래(주 60시간 이상) 약 0.37%(스펙 초안은 0.3%, 문서를 0.37% 로 맞춤)
- 멤버 평균(w주 창)의 SD 배율 `sqrt(0.8 + 0.2/w)`: 같은 멤버의 주별 시청 시간이 공유하는 비중 0.8 가정
- 오프라인 NDCG 점수(순위만 스펙)
- 대리 지표(7일 내 2화 이상 시청) 효과 = 시청 시간 상대 효과 × 0.8 (R3 +0.88%p). 스펙에는 효과가 없다
- 재생 중 2분 내 이탈 효과: R2 +3.5%p(스펙은 "증가"만), R3 −0.3%p, R4 −0.2%p, R6 +0.4%p, R7 −0.1%p
- 밴딧: 하루 신규 6만 명, 28일, 사전분포 N(6.5, 3²), 탐색 하한 2%, 반복 100회, 리텐션 판독일 = 실험 종료 28일 뒤

## 스펙과 다르게 한 결정 (PR에도 기재)
1. **s3 를 `readout` 종류로 둠**: 스크리닝에는 A/A 단계가 없어서, 실행 화면이 A/A 버튼을 내지 않도록 했다. s3 와 s4 는 같은 시뮬레이션을 보여준다.
2. **s6 를 설계 폼 + 시뮬레이션 패널로 구현**: 결정(ship, long_term)은 `p3` 설계 폼으로 받고, 선택한 장기 검증 방식의 패널(홀드아웃 검출력, 연장 검출력, 밴딧)을 `p3_readout` 에서 보여준다. 별도 결정 제출은 없다.
3. **s4 결선 후보 선택은 조합 5개 중 고르는 결정**으로 만들었다(R3·R4, R3·R4·R7, R2·R3·R4, R1·R3·R4, R2·R3). 실제 결선 후보는 s5 설계에서 다시 고른다.
4. **s1 의 `OFFLINE_ONLINE_GAP` 플래그**: 시뮬레이션이 없는 단계라 `diagnoseFlags()` 순수 함수로 두고 테스트로 검증했다. 강사 보드(sim_runs 기반)에는 아직 연결하지 않았다.
5. **UNDERPOWERED 의 달성 검정력**: A/B/n 스크리닝은 "1% 시청 시간(또는 +0.15%p 리텐션) 효과"를 보정된 유의수준으로 잡을 검정력, 결선은 후보 중 진짜 효과가 가장 큰 후보를 잡을 검정력이다. 모든 후보의 진짜 효과가 0 이면 정의하지 않는다.
6. **NOVELTY 플래그**: 메인이 시청 시간이고, 첫 주 제외를 하지 않았고, 분석 기간(종료 주차)이 4주 미만이면 표시한다. 리텐션·대리 지표 메인은 신규성을 얹지 않으므로(#8) 표시하지 않는다. peek_stop 은 첫 주를 빼지 않으면 1주차, 빼면 2주차에 멈춘다. sequential 도 그룹당 수십만 명이면 1주차에 경계를 넘어 신규성 구간에서 멈추고 NOVELTY 가 뜬다(PEEKED 는 peek_stop 일 때만).
7. **리텐션 메인은 4주 미만이면 거부**: "28일 리텐션은 최소 4주"라는 스펙 문장을 입력 검증으로 구현.
8. **대리 지표에는 신규성을 얹지 않음**.
9. **밴딧의 "추정치 편향"**: 리텐션 효과 자체는 편향되지 않지만(늦게 배정된 멤버는 경과 주가 짧아 효과가 덜 보인다는 효과는 있음), 시청 시간 추정치는 트래픽이 몰린 날(예: 신규성이 높은 초반의 R2)이 더 많이 반영돼 치우친다. 반복 100회 평균으로 보여준다.
10. **A/B/n 의 기간 효과**: 윈저라이징·CUPED 는 스크리닝에는 적용하지 않는다(스펙의 abn 입력에 없음).
11. **인터리빙 계획 표본·달성 검정력은 한 표본 z 검정(선호 vs 0.5) 기준**이다. 실제로 돌리는 검정과 같은 식: n = (z_α/2·0.5 + z_β·√(p(1−p)))² / (p − 0.5)². 선호 0.52·80% 에 쌍당 4,904명(Bonferroni 8개면 7,990명), 쌍당 1만 명의 검정력 0.979(Bonferroni 0.897). 예전에는 두 그룹 비율 공식을 써서 9,806명 / 0.808 로 약 2배 부풀려져 있었다.
12. **A/B/n 의 UNDERPOWERED** 는 Bonferroni 보정 유의수준 기준이면 확실히 뜬다(10%·2주·9군 검정력 0.22). BH·보정 없음은 계획 유의수준을 0.05 로 보므로 검정력이 0.502 로 기준선(0.5) 바로 위라 뜨지 않는다.
13. **표본 크기 참고값(§2-1)**: 시청 시간 +1%, 5%·80% 기준 그룹당 1주 창 원시 30.1만 / 윈저라이징 25.4만 / +CUPED 13.7만, 4주 창 25.6만 / 21.6만 / 11.6만, 리텐션 +0.15%p 45.0만.

## 한계
- 효과 값은 시나리오 범위에 맞춘 가상 값이다.
- 인터리빙은 멤버 단위 이항 모형이며 실제 랭킹 병합(Team Draft 알고리즘)을 구현하지 않는다. 위치 편향은 +0.015 상수로만 표현한다.
- 결선의 주별 노이즈는 주마다 독립으로 두었다(멤버 간 지속 성분은 SE 배율로만 반영).
- 시나리오 7 에서 R2 의 진짜 정상 상태 효과(+0.4%)는 이 표본 크기에서 기대 z 가 약 2 로 경계에 있고, 노이즈 draw(salt)에 따라 유의 여부가 갈린다. 지금 salt 에서는 p = 0.052 로 겨우 유의하지 않지만, 시드 12개 중 9개에서는 p < 0.05 였다. 그래서 문서·테스트는 "R2 유의 아님" 대신 "R2 효과(+0.7% 미만)가 R3 의 0.7배 미만"을 확인한다(시드 12개 모두 성립).
